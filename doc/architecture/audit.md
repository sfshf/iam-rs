# Audit Server

Audit Server is a gRPC-based microservice responsible for centralized audit logging across all microservices in the distributed system.

It provides a unified mechanism for collecting, recording, querying, and managing audit events generated by individual microservices. It enables the system to maintain a comprehensive and traceable record of security-related activities, user operations, administrative actions, and critical business events.

The core service interfaces include:

- **Audit Event Ingestion**: Receive and record audit events submitted by other microservices.
- **Audit Log Query**: Retrieve and search audit records based on various criteria, including time range, actor, action, resource, service, and event type.
- **Audit Log Retrieval**: Retrieve detailed information about a specific audit event.
- **Audit Event Management**: Manage audit event metadata, event categories, and event schemas.
- **Audit Log Export**: Export audit records for external analysis, compliance reporting, or archival purposes.
- **Audit Log Integrity Verification**: Ensure the integrity and traceability of audit records and detect unauthorized modifications or tampering.

Audit Service provides a centralized and consistent audit trail for the entire distributed system, helping organizations meet security, accountability, and compliance requirements.
