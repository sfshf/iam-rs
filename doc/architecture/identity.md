# Identity Server

Identity Server is a gRPC-based microservice responsible for identity management, authentication, and authorization. It provides centralized identity-related capabilities and exposes the following core service interfaces:

### Core Features

- **Identity Management** – Provides user registration, profile management, user lookup, and account lifecycle management.
- **Authentication** – Supports user login, logout, credential verification, and password management.
- **Token Management** – Provides access token issuance, token validation, token refreshing, and token revocation.
- **Multi-Factor Authentication (MFA)** – Supports additional authentication mechanisms to enhance account security.
- **Session Management** – Provides session tracking, session revocation, and centralized session lifecycle management.
- **Account Security** – Supports account status management, password recovery, and security-related operations.
- **gRPC API** – Exposes identity and authentication capabilities through strongly typed, high-performance gRPC APIs.
